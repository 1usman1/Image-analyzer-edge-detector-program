# Image Analyzer — Edge Detector

A Python image analyzer that uses the **Sobel operator** to detect and highlight edges in images.

The program analyzes differences in pixel brightness to identify edges. Detected edges are displayed in white, while non-edge areas are displayed in black.

The graphical user interface is built using **Tkinter**.

## Required Libraries

The following Python libraries are required:

- Pillow
- NumPy

## Features

- Load and display images
- Convert images to grayscale
- Detect edges using the Sobel operator
- Adjustable edge-detection threshold
- Display edge statistics
- Save the processed result
