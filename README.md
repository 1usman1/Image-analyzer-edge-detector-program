# Image-analyzer-edge-detector-program
This is an image analyzer software, coded with python, this software uses the "sobel kernel solution" to find and highlight edges of a picture. 
It uses sobel kernel solution to detect pixels that differ in brightness and the program highlights it with a white color, while the rest is colored black. 
The user interface is built using tkinter.
------------------------------------------------
## Required python libraries (not included in python by default):
1: pillow
2: numpy
------------------------------------------------
## Features:
1: Load and display images
2: Convert images to grayscale
3: Detect edges using the Sobel operator
4: Adjustable edge-detection threshold
5: Display edge statistics
6: Save result
